How this demo works

This is a plugin-based MVP-style LMS front-end: catalogue, curriculum, enrolment and learner progress run in your browser (localStorage). In production, the same front-end connects to a Pakistani payment gateway (JazzCash / EasyPaisa / card via a PK processor). This demo takes no payment and stores nothing on a server.
